# 天下無雙・放置版 — 版本 V1.0.7

單機放置型網頁遊戲。直接用瀏覽器開啟 `index.html` 即可遊玩，不需要伺服器。

## 檔案結構

| 檔案 | 說明 |
|---|---|
| `index.html` | 遊戲主檔（HTML 結構與內建樣式；V1.0.7 起遊戲邏輯已移到 `data/`） |
| `data/*.js` | **遊戲邏輯，共 31 個模組**（資料、戰鬥、背包、煉器、副本、介面…）。哪個功能在哪個檔、載入順序、常見需求對照表都寫在 [`data/README.md`](data/README.md) |
| `lobby.js` | 登入頁、角色選擇頁（4 個存檔欄位）、創建角色頁 |
| `lobby.css` | 上面三個頁面與倉庫視窗的樣式 |
| `warehouse.js` | 共用倉庫（同模式角色共用；一般／奇緣模式各自獨立） |
| `theme.css` | 介面主題 V2（墨藍鎏金），含戰鬥血條打擊感樣式 |
| `ui-buttons.css` | 按鈕、資源卡、角色徽記的樣式（載在 `theme.css` 之後覆蓋） |
| `ui-icon-masks.css` | **自動產生**，請勿手改。圖示遮罩以 data URI 內嵌 |
| `圖片/ui/mask/*.png` | 圖示遮罩來源（128px，只有 alpha 有意義） |
| `圖片/ui/avatar-ring.png` | 左上角色徽記的火焰龍紋圓環 |
| `圖片/bg.jpg` | 遊戲背景圖（雪山紅葉） |
| `圖片/bg-warehouse.jpg` | 共用倉庫視窗背景圖（仙鶴夜色） |
| `tools/` | 圖示抽取與 CSS 產生腳本，以及示意圖原檔 |

`index.html` 依序載入 `lobby.css` → `theme.css` → `ui-buttons.css` → `ui-icon-masks.css`，後面的會覆蓋前面的。

## 換圖示的流程

圖示是從示意圖抽出來的 alpha 遮罩，顏色由 CSS 控制（所以能做金色漸層、Boss 血紅、選中變亮）。要換圖示：

1. 把新的示意圖放進 `tools/reference/`
2. 在 `tools/extract-icons.py` 的 `JOBS` 調整裁切框與亮度門檻
3. 執行兩行：

```bash
python tools/extract-icons.py
python tools/build-icon-css.py
```

抽取結果會存到 `圖片/ui/mask/`，對照圖在 `tools/preview/`。抽取腳本會自動警告哪一顆可能被裁切到。

**注意**：`ui-icon-masks.css` 必須用腳本重新產生，不能只換 PNG——因為 CSS 的 `mask-image` 受 CORS 限制，用 `file://` 直接開網頁時外部遮罩檔會載入失敗（元素會整個消失），所以遮罩是內嵌進 CSS 的。

`tools/diagnose.html` 是介面診斷頁，圖示沒顯示時可以用它逐項檢查。

## 版本紀錄與規則

**規則：之後每一次修改（每一批更新）版本號最後一碼自動 +1**，例如 V1.0.4 → V1.0.5 → V1.0.6。已推送的版本不再回頭改版本號。

改版本號時要同步改這幾處（搜尋目前版本號即可全部找到）：
1. `data/config.js` 的 `const GAME_VERSION='v1.0.7';`（登入頁版號會自動讀這個）
2. `index.html` 更新選單標題「天下無雙・放置版 V1.0.7」與「目前版本：V1.0.7」，並把更新選單內容換成該版的更新重點
3. `data/system-ui.js` 設定頁底部「V1.0.7 · …」

（`index.html` 裡另外兩處 `GAME_VERSION` 是程式讀取常數，會自動跟著更新，不必手改。存檔沒有任何版本比對邏輯，`G.version` 只寫不讀，所以改版號不會影響既有存檔。）

### 修正：自動喝水、Boss 重生、主城暫停

只改了 `index.html`：
- **自動喝水設定無效**：原本喝水門檻寫死在戰鬥策略（均衡 50%、強攻 30%、殺無赦 20%），「吃藥設定」裡的「HP 低於 %」完全沒被讀取，所以設 95% 也不會喝。現在改用玩家設定：HP 用 `potionHpPct`、治癒魔法用 `healHpPct`、MP 用 `mpPotionPct`（原本殺無赦策略永遠不喝 MP，也一併移除）。
- 自動喝水不再需要開啟掛機：手動戰鬥與沙魔巢穴也會依設定吃藥（自動撤退仍只在掛機時）。
- 戰鬥策略說明改成只寫撤退門檻（例：均衡「HP 25% 撤退」），不再寫喝水百分比。
- **Boss 重生時間**：原本少乘 1000（毫秒），打倒後約 0.1 秒就重生；現在固定 5 分鐘（常數 `BOSS_RESPAWN_MS`）。
- **裝備升品（凡品→天品）素質沒變**：原本升品只記在「同名共用品質」（`G.inventoryQuality`），所有數值顯示都用未乘品質的原始值，而且保留下來的那一件常常還是舊品質，同名的新掉落卻會直接繼承升品。現在品質倍率（凡 1／靈 1.08／玄 1.18／地 1.32／天 1.5）直接乘進每一件裝備自己的攻／防／HP／MP／屬性，顯示＝實際效果。3合1 以實體裝備計算：保留目標那件的強化、精煉、寶石、詞綴，只消耗另外 2 件同品質同部位的裝備，鎖定裝備不會被吃掉。舊存檔進入時自動轉換一次（`migrateEquipQuality`），原本實際生效的戰力不變。相關函式：`QUALITY_MUL`、`scaleEquipStats`、`bakeEquipQuality`、`migrateEquipQuality`、`synthesize`、`makeEquip`。`warehouse.js` 取出舊裝備時也會做同樣轉換。
- **主城畫面暫停遊戲**：原本切到「主城／江湖」頁面時整個遊戲迴圈停止（戰鬥、掛機、副本都卡住）。現在只在登入／選角畫面停止。按「回 主城」仍會照原設計停止掛機。

### 新增：奇緣模式

改了 `index.html`、`lobby.js`、`lobby.css`、`warehouse.js`：
- **選擇方式**：只能在「創建角色」畫面選擇「一般模式／奇緣模式」，建立後無法更改（存在存檔的 `G.mode`，`'normal'` 或 `'qiyuan'`；舊存檔一律視為一般模式）。選角色畫面與上方角色資訊會標示「奇緣」。
- **不能強化**：奇緣模式下強化、精煉、洗煉、3合1 升品停用（`qiyuanBlock()`）；**開孔與鑲嵌開放使用**。煉器殿在奇緣模式只顯示開孔與靈石鑲嵌。
- **掉落裝備隨機**：打怪、Boss、離線、沙魔巢穴掉落的裝備（`gainEquipDrop()` → `rollQiyuanEquip()`）隨機產生：
  - 品階：一般怪 凡46%／靈30%／玄15%／地7%／天2%；Boss 凡8%／靈27%／玄33%／地22%／天10%
  - 強度：一般怪 85%～125%，Boss 95%～130%（乘在裝備基礎數值上）
  - 強化值：+0 起，每級約 50%（Boss 62%）機率再 +1；上限 = 3 + 怪物等級/12（Boss 再 +2），最高 +15
  - 背包、提示框、戰鬥紀錄會顯示「+強化值 · 強度%」
- **倉庫不共通**：一般模式 `txws_idle_warehouse_v1`、奇緣模式 `txws_idle_warehouse_qiyuan_v1`，視窗標題會顯示目前模式。
- **可選擇特定那一件**：背包「選擇」→「裝備／販賣／分解」現在會針對點選的那一件（`equipItemAt`），不再固定拿最後一件（一般模式也受惠）。
- 商店仍可購買裝備（+0、原本品質）；如果奇緣模式也要禁止商店裝備，改 `buyEquip` 加上 `if(isQiyuan())` 即可。
- 數值都集中在 `rollQiyuanEquip()`，要調整機率或上限改那裡。

## 如何新增人物圖片（給 AI／維護者）

現在人物圖片都是黑框，因為圖片路徑是空的。只要做兩步：

### 第 1 步：放圖片

在 `index.html` 旁邊建立資料夾 `assets/char/`，把圖片放進去，例如：

```
天下無雙放置版/
├─ index.html
├─ lobby.js
└─ assets/char/
   ├─ sword_m.png   劍宗 男
   ├─ sword_f.png   劍宗 女
   ├─ halberd_m.png 戟門 男
   ├─ halberd_f.png 戟門 女
   ├─ trick_m.png   詭流 男
   ├─ trick_f.png   詭流 女
   ├─ magic_m.png   幻道 男
   └─ magic_f.png   幻道 女
```

檔名可以自己取，第 2 步填對就好。建議用直式、背景透明的 PNG（約 3:4），人物腳底對齊圖片底部。

### 第 2 步：改 `lobby.js` 最上面的 `PORTRAITS`

找到這段（在檔案開頭附近）：

```js
const PORTRAITS = {
  劍宗:{m:'',f:''}, 戟門:{m:'',f:''}, 詭流:{m:'',f:''}, 幻道:{m:'',f:''}
};
```

把空字串換成圖片路徑（`m`＝男，`f`＝女）：

```js
const PORTRAITS = {
  劍宗:{m:'assets/char/sword_m.png',   f:'assets/char/sword_f.png'},
  戟門:{m:'assets/char/halberd_m.png', f:'assets/char/halberd_f.png'},
  詭流:{m:'assets/char/trick_m.png',   f:'assets/char/trick_f.png'},
  幻道:{m:'assets/char/magic_m.png',   f:'assets/char/magic_f.png'}
};
```

存檔後重新整理網頁就完成了。圖片會同時出現在「角色選擇」的拱門和「創建角色」的大框。

### 注意

- 路徑是相對於 `index.html` 的位置。
- 某個欄位留空 `''` 就繼續顯示黑框，所以可以一張一張慢慢補。
- 只需要改 `PORTRAITS`，其他程式碼都不用動。
- 門派名稱（劍宗、戟門、詭流、幻道）必須和遊戲裡 `CLASSES` 的名稱完全相同，不要改字。
