# 官網資料庫（原始備份）

從《新天下無雙》官網「資料大全」抓下來的結構化資料，共 **28 個 JSON、1,427 筆**。
**遊戲不會載入這個資料夾**，它只是原始備份與後續維護的依據。

來源：`https://tx.7ma.cn/gamedata/`（簡體）。這裡保留**簡體原文**，
轉成繁體與遊戲格式的版本在 `../data/official-extra.js` 與 `../data/official-skill-data.js`。

## 怎麼重抓 / 怎麼更新

兩支腳本在 `.claude/worktrees/.../scratchpad/`（不在 git 裡，需要時可重建）：

| 腳本 | 做什麼 |
|---|---|
| `scrape.ps1` | 從官網抓所有資料頁 → 產生本資料夾的 JSON |
| `gen.ps1` | 讀本資料夾 → 產生 `../data/official-extra.js`（怪物、地圖、血珀、套裝） |
| `genskill.ps1` | 讀技能 JSON → 產生 `../data/official-skill-data.js`（招式公式） |

官網改版後要更新資料：依序跑 `scrape.ps1` → `gen.ps1` → `genskill.ps1`，
然後用 `node --check` 檢查產生的兩個 .js，再進遊戲驗證。

**不要手改 `data/official-extra.js` 與 `data/official-skill-data.js`**，它們會被重新產生覆蓋掉。
要調整數值請改產生腳本，或改 `data/config.js`／`data/monster.js` 裡的係數。

## 兩個踩過的坑（重抓時注意）

1. **PowerShell 變數名稱不分大小寫**：`$slot` 會覆蓋 `$SLOT`。對照表一律用 `_MAP` 結尾命名。
2. **`ConvertTo-Json` 在 PS 5.1 會把巢狀陣列包成 `{"value":[…],"Count":n}`**：
   陣列要自己輸出（`gen.ps1` 裡的 `JsonVal`／`RowsJson`）。

簡體轉繁體用 `[Microsoft.VisualBasic.Strings]::StrConv(..., TraditionalChinese, 2052)`，實測正確。
