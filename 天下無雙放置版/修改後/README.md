# 修改後（本次更新的檔案）— 版本 V1.0.3

這個資料夾是本次更新的完整副本，4 個檔案直接覆蓋到「天下無雙放置版」根目錄即可使用。

| 檔案 | 說明 |
|---|---|
| `index.html` | 原遊戲主檔，只改了幾處掛接點（多存檔、進入角色前不存檔、倉庫按鈕、返回角色選擇） |
| `lobby.js` | 新增：登入頁（點任意處進入）、角色選擇頁（4 個角色欄位，人物暫以黑色塊顯示）、創建角色頁 |
| `lobby.css` | 新增：上面三個頁面與倉庫視窗的樣式 |
| `warehouse.js` | 新增：共用倉庫（同模式角色共用；一般／奇緣模式各自獨立） |

## 版本紀錄與規則

**規則：之後每一次修改（每一批更新）版本號最後一碼自動 +1**，例如 V1.0.3 → V1.0.4 → V1.0.5。已推送的版本不再回頭改版本號。

改版本號時要同步改 `index.html` 裡這幾處（搜尋目前版本號即可全部找到）：
1. `const GAME_VERSION='v1.0.3';`（登入頁版號會自動讀這個）
2. 更新選單標題「天下無雙・放置版 V1.0.3」與「目前版本：V1.0.3」，並把更新選單內容換成該版的更新重點
3. 設定頁底部「V1.0.3 · …」
4. 本 README 最上方標題的版本號，並在下表新增一列

| 版本 | 日期 | 狀態 | 內容 |
|---|---|---|---|
| V1.0.3 | 2026-09-23 | 已推送 | 登入／選角（4 格）／創角、共用倉庫、移除狀態神通、增益 2 槽修正、副本進入與條件提示、自動喝水修正、Boss 重生 5 分鐘、主城不暫停、升品素質修正、登入主視覺、倉庫移到下方選單、奇緣模式（含開放開孔與鑲嵌） |
| V1.0.4 | — | 下一版 | 下一次修改時使用 |

四個檔案要放在同一層資料夾。另外 `圖片/login-bg.jpg` 是登入頁主視覺（由作者提供的 `圖片/登入圖.png` 壓縮成 JPG，3.6 MB → 約 500 KB，網頁載入較快），需一起放進 `圖片/` 資料夾。

### 登入頁改用主視覺圖片、倉庫移到下方選單

- 登入頁改為「墨黑・鎏金・素白」風格，配合主視覺：桌機時主圖在左（左右與底部淡出），右側為紅色「放置版」印章、金色分隔線、金框按鈕與版號；背景用同一張圖模糊放大延續色調，並有飄落的金色光點。手機直式時主圖鋪滿畫面，按鈕疊在下方墨色漸層上。圖上已有「天下無雙」書法字，所以不再另外顯示文字標題。
- 要換登入圖：把新圖存成 `圖片/login-bg.jpg` 覆蓋即可（建議直式 2:3）；程式位置在 `lobby.js` 的 `lb-login-art` 與 `lobby.css` 的 `.lb-login-blur`。
- 遊戲上方的「倉」按鈕移除，改放在下方選單「背包」與「神通」中間（下方選單由 8 格變 9 格）。背包頁與設定頁的倉庫按鈕保留。

### 已移除：狀態神通（自動）

只改了 `index.html`：
- 刪除「神通」頁的「狀態神通（自動）」說明卡。
- 掛機不再自動輪詢施放回復類（heal）與淨化類（cleanse）神通；刪除 `cleanseSkillList()`，並拿掉 `autoSupport()` 裡的相關段落。
- 回復類神通仍可以在「設定 → 吃藥／治癒設定 → 自動施法治癒魔法」手動選用（這是另一個獨立功能，沒有刪）。

### 修正：增益神通（2 槽）

只改了 `index.html`：
- 原本「增益神通／2槽」放了技能卻從來不會施放；現在掛機且開啟自動選招時，AI 會自動施放增益槽內的神通（增益生效中不重複施放，並保留 MP 下限）。
- 增益改為限時 20 秒：加速（haste）縮短出手間隔；減傷（guard）降低受到的傷害（最多 60%）。原本加速每一幀都被重算清掉；減傷因運算子優先順序錯誤，實際效果是減傷 65% 且整場不消失。
- 敵方「破防」原本觸發一次就永久生效，改為持續 3 次敵方行動。
- 戰鬥畫面會顯示增益剩餘秒數，敵方狀態多顯示「破防」。
- 相關函式：`applyBuff`、`buffValue`、`buffRemain`、`buffText`、`autoSupport`、`castSkill`、`enemyAttack`、`combatTick`。

### 修正：副本進入

- 原本自動狩獵中點選副本（五行妖閣、魂魄副本、聚妖谷、沙魔巢穴）或 Boss 會無聲失敗；其中魂魄副本會照樣用掉今日次數，聚妖谷會照樣扣 100,000 靈石。現在會先中斷一般狩獵再進入（`dungeonPrepare`）。
- 點選任何副本都會先跳出條件視窗（`openDungeonPrompt`），列出等級、次數、靈石等條件（✔／✘）及注意事項；條件不足時「進入」按鈕無法按。
- 已有副本或 Boss 戰鬥進行中時，不能再進入另一個副本。

### 修正：自動喝水、Boss 重生、主城暫停

只改了 `index.html`：
- **自動喝水設定無效**：原本喝水門檻寫死在戰鬥策略（均衡 50%、強攻 30%、殺無赦 20%），「吃藥設定」裡的「HP 低於 %」完全沒被讀取，所以設 95% 也不會喝。現在改用玩家設定：HP 用 `potionHpPct`、治癒魔法用 `healHpPct`、MP 用 `mpPotionPct`（原本殺無赦策略永遠不喝 MP，也一併移除）。
- 自動喝水不再需要開啟掛機：手動戰鬥與沙魔巢穴也會依設定吃藥（自動撤退仍只在掛機時）。
- 戰鬥策略說明改成只寫撤退門檻（例：均衡「HP 25% 撤退」），不再寫喝水百分比。
- **Boss 重生時間**：原本少乘 1000（毫秒），打倒後約 0.1 秒就重生；現在固定 5 分鐘（常數 `BOSS_RESPAWN_MS`）。
- **裝備升品（凡品→天品）素質沒變**：原本升品只記在「同名共用品質」（`G.inventoryQuality`），所有數值顯示都用未乘品質的原始值，而且保留下來的那一件常常還是舊品質，同名的新掉落卻會直接繼承升品。現在品質倍率（凡 1／靈 1.08／玄 1.18／地 1.32／天 1.5）直接乘進每一件裝備自己的攻／防／HP／MP／屬性，顯示＝實際效果。3合1 以實體裝備計算：保留目標那件的強化、精煉、寶石、詞綴，只消耗另外 2 件同品質同部位的裝備，鎖定裝備不會被吃掉。舊存檔進入時自動轉換一次（`migrateEquipQuality`），原本實際生效的戰力不變。相關函式：`QUALITY_MUL`、`scaleEquipStats`、`bakeEquipQuality`、`migrateEquipQuality`、`synthesize`、`makeEquip`。`warehouse.js` 取出舊裝備時也會做同樣轉換。
- **主城畫面暫停遊戲**：原本切到「主城／江湖」頁面時整個遊戲迴圈停止（戰鬥、掛機、副本都卡住）。現在只在登入／選角畫面停止。按「回 主城」仍會照原設計停止掛機。

### 新增：奇緣模式

改了 `index.html`、`lobby.js`、`lobby.css`、`warehouse.js`：
- **選擇方式**：只能在「創建角色」畫面選擇「一般模式／奇緣模式」，建立後無法更改（存在存檔的 `G.mode`，`'normal'` 或 `'qiyuan'`；舊存檔一律視為一般模式）。選角色畫面與上方角色資訊會標示「奇緣」。
- **不能強化**：奇緣模式下強化、精煉、洗煉、3合1 升品停用（`qiyuanBlock()`）；**開孔與鑲嵌開放使用**。煉器殿在奇緣模式只顯示開孔與靈石鑲嵌。
- **掉落裝備隨機**：打怪、Boss、離線、沙魔巢穴掉落的裝備（`gainEquipDrop()` → `rollQiyuanEquip()`）隨機產生：
  - 品階：一般怪 凡46%／靈30%／玄15%／地7%／天2%；Boss 凡8%／靈27%／玄33%／地22%／天10%
  - 強度：一般怪 85%～125%，Boss 95%～130%（乘在裝備基礎數值上）
  - 強化值：+0 起，每級約 50%（Boss 62%）機率再 +1；上限 = 3 + 怪物等級/12（Boss 再 +2），最高 +15
  - 背包、提示框、戰鬥紀錄會顯示「+強化值 · 強度%」
- **倉庫不共通**：一般模式 `txws_idle_warehouse_v1`、奇緣模式 `txws_idle_warehouse_qiyuan_v1`，視窗標題會顯示目前模式。
- **可選擇特定那一件**：背包「選擇」→「裝備／販賣／分解」現在會針對點選的那一件（`equipItemAt`），不再固定拿最後一件（一般模式也受惠）。
- 商店仍可購買裝備（+0、原本品質）；如果奇緣模式也要禁止商店裝備，改 `buyEquip` 加上 `if(isQiyuan())` 即可。
- 數值都集中在 `rollQiyuanEquip()`，要調整機率或上限改那裡。

## 如何新增人物圖片（給 AI／維護者）

現在人物圖片都是黑框，因為圖片路徑是空的。只要做兩步：

### 第 1 步：放圖片

在 `index.html` 旁邊建立資料夾 `assets/char/`，把圖片放進去，例如：

```
天下無雙放置版/
├─ index.html
├─ lobby.js
└─ assets/char/
   ├─ sword_m.png   劍宗 男
   ├─ sword_f.png   劍宗 女
   ├─ halberd_m.png 戟門 男
   ├─ halberd_f.png 戟門 女
   ├─ trick_m.png   詭流 男
   ├─ trick_f.png   詭流 女
   ├─ magic_m.png   幻道 男
   └─ magic_f.png   幻道 女
```

檔名可以自己取，第 2 步填對就好。建議用直式、背景透明的 PNG（約 3:4），人物腳底對齊圖片底部。

### 第 2 步：改 `lobby.js` 最上面的 `PORTRAITS`

找到這段（在檔案開頭附近）：

```js
const PORTRAITS = {
  劍宗:{m:'',f:''}, 戟門:{m:'',f:''}, 詭流:{m:'',f:''}, 幻道:{m:'',f:''}
};
```

把空字串換成圖片路徑（`m`＝男，`f`＝女）：

```js
const PORTRAITS = {
  劍宗:{m:'assets/char/sword_m.png',   f:'assets/char/sword_f.png'},
  戟門:{m:'assets/char/halberd_m.png', f:'assets/char/halberd_f.png'},
  詭流:{m:'assets/char/trick_m.png',   f:'assets/char/trick_f.png'},
  幻道:{m:'assets/char/magic_m.png',   f:'assets/char/magic_f.png'}
};
```

存檔後重新整理網頁就完成了。圖片會同時出現在「角色選擇」的拱門和「創建角色」的大框。

### 注意

- 路徑是相對於 `index.html` 的位置。
- 某個欄位留空 `''` 就繼續顯示黑框，所以可以一張一張慢慢補。
- 只需要改 `PORTRAITS`，其他程式碼都不用動。
- 門派名稱（劍宗、戟門、詭流、幻道）必須和遊戲裡 `CLASSES` 的名稱完全相同，不要改字。
