### 遊戲改版時更新資料

1. 跑爬蟲：雙擊 `桌面\爬蟲\ro-survivors-tool\爬RO倖存者.bat`
   （爬蟲的 REPORT.md 從 f254752 起讀不到翻譯表、差異全是 0——那是給舊書籤用的，不用管。
   **要知道改了什麼**：`node tools\diff_text.js 舊版 新版 > diff.txt` 看文字；
   抽資料前先把 `rs-crawl\_wiki_dump.json` 複製一份，抽完跑 `python tools\diff_dump.py 舊的dump` 看數值有沒有變。）
2. 開離線版（`.claude\launch.json` 的 `rs-offline`，或 `開啟最新離線版.bat`），網址加 `?notools`，
   遊戲語言切成**繁體中文**。
3. 在瀏覽器主控台（F12）執行：
   ```
   await import('/__wiki_dump.js?' + Date.now())
   ```
   會存成 `桌面\爬蟲\ro-survivors-tool\rs-crawl\_wiki_dump.json`；畫面上會列出找不到的資料表（⚠）。
4. **檢查中文有沒有變化**：`node tools\check_zh.js`（預設最新一次爬蟲的版本）。會列出
   官方中文表漏翻的字串、物品／卡片／怪物／技能名稱在 names.txt 沒有譯名（官方也沒翻）的、
   zh.js 的字尾表、**rs_offline.py 所有修補（無盡之塔、隱藏職業、GM、中文）對新版還對不對得上**（每項要剛好 1 處）。
   缺的名稱加到 `tools\zh\names.txt`（`@英文<Tab>中文`）。
   官方改了譯名（diff_text.js 的「中文改」）時，names.txt 裡同一個東西要改成跟官方一樣（官方說明文字裡出現的也算），
   手寫的頁面（`wiki/js/page-*.js`）裡寫死的名稱也要搜一下。
5. 在這個資料夾執行 `python tools\build_wiki.py`，產生 `wiki/data/*.js`。
   列出「沒有中文」的名稱同樣加到 names.txt 再跑一次。資料有變就把 `index.html` 的 `?v=` 全部 +1。
6. **離線版的中文**：`python tools\pack_offline.py`（把 names.txt 填進 `offline\zh.js`、重做 zip 和 version.json）。
   只補翻譯不用改 TOOL_VERSION：玩家的離線工具（v1.5 起）看到同版本但檔案不同也會自動更新。
7. 本機預覽：`.claude\launch.json` 的 `rs-wiki`（http://localhost:8390），確認後推上 GitHub。

### 資料來源與規則（2026-11-09，遊戲 20261109_00ec63b）

- 遊戲每次改版變數名會變，`wiki_dump.js` 一律用「資料形狀」找表（例如有 `bash.maxLevel` 的物件＝技能表）。
- 職業、技能、天賦、關卡名稱用遊戲自己的中文；**怪物、物品、卡片名稱遊戲只有英文**，用 `tools/zh/names.txt` 的台版譯名。
- 裝備掉率是遊戲程式的公式：首領每件 10%～15%（依 RO 原始掉率），首領的武器固定 5%；一般怪物 0.015%～0.03%。
  卡片掉率不在客戶端程式裡，只寫「非常稀有，首領較容易」。
- 寵物清單在 main.js 內部（沒有匯出），`wiki_dump.js` 直接解析 main.js 原始碼的 `rt("poring",9001,10013,[…])` 呼叫，
  加成函式是從 soul_linker 匯入的，用匯入對照表找到匯出名稱再算出中文。規則：蛋一般 0.01%、MVP 0.1%；
  親密度從 250 開始、每 5 秒 +1、親密 750（×0.75）、忠誠 910（×1）、普通 ×0.5；飾品 200 卡普拉點數、×1.5；
  進化要前一隻忠誠＋打倒那隻首領 5 次。親密度「Neutral／Cordial」遊戲沒翻，用台版「普通／親密」。
- 沒有任何來源的裝備（90 件左右，多半有固定效果）是舊版留下的，標成「目前無法取得」。
- 圖片直接連到 `https://ro-survivors.com/assets/…`（`core.js` 的 `IMG_BASE`）。

## 書籤的運作方式

1. 遊戲的翻譯函式查 `{es:null, en:英文表}[設定語言]`。書籤在 `Object.prototype` 放一個 `zh` getter，
   只有遇到這張語言表時才回傳中文表，再點語言選單裡加上的「繁體中文」切換。
2. 中文表用**西文原文**當鍵；沒翻到的字會退回遊戲自己的英文。
3. 怪物、物品、卡片、技能名是遊戲直接顯示的英文原名（不經過翻譯函式），書籤用名稱表在畫面上替換
   （DOM 的 MutationObserver＋canvas 的 fillText）。
4. 遊戲公告是主程式內嵌的英文 markdown，書籤在公告視窗（`#news-body`）變動時逐段換成中文，
   日期標題自動轉成「2026 年 11 月 8 日」。
5. 設定存檔時把 lang 存回原本的語言，沒點書籤時遊戲照常是英文。
6. **維修公告**（V3 起）：遊戲每隔一段時間讀 `https://ro-survivors.com/status.json`，
   格式 `{"state":"ok|info|warn|maintenance","at":毫秒,"message":"西文 || 英文"}`。
   - `at`（倒數警告）：遊戲自己格式化時間，書籤讓中文模式的所有日期時間都用台灣時區（Asia/Taipei）。
   - `message` 是自由文字，時間寫成「22:00 (Madrid time)」：書籤攔下 status.json，把
     「HH:MM (Madrid／Spain／CET／UTC…)」換算成「台灣時間 11/9（一）05:00」（取接下來第一個那個時刻，3 小時內剛過的也算），
     常見句子用 `ro-zh.src.js` 裡的 `MAINT_SENT` 表翻成中文；沒對到的句子保留原文、只換名稱。
     有新句型就在 `MAINT_SENT` 加一行（正規式＋中文，`{T}` 是換算好的時間、`{1}` 是第一個括號）。
7. **天賦頁**（V4 起）：首頁「天賦」原本是 `<a href="talents.html" target="_blank">` 開新分頁（新分頁沒書籤＝英文）。

   載入後把書籤自己（`import.meta.url`）插進 iframe，在天賦頁的 ES/EN 旁加「中文」並切過去。
   跳窗裡的「開始／回到遊戲」＝關閉跳窗。直接開 talents.html 再點書籤也會切中文。
   天賦頁字串（talents.js）和遊戲共用翻譯表；`1st job` 不在表裡，放在 names.txt。
   爬蟲會一起下載 `talents.html`（它不在 sw.js 的 PRECACHE 裡）。
   - 2026-11-09 第一次看到的公告：`Maintenance at 22:00 (Madrid time). Finish your Endless Tower runs before then.`

## 遊戲更新時的作業流程（只翻新增的部分）

1. **跑爬蟲**：雙擊 `桌面\爬蟲\ro-survivors-tool\爬RO倖存者.bat`
   - 遊戲沒更新：一個檔案都不下載，直接重做報告。
   - 遊戲有更新：只下載檔名變了的程式檔（通常 1～3 個）＋ index.html，其他從上一版複製。
   - 產出 `rs-crawl\<日期>_<commit>\REPORT.md`：這次新增／修改／移除的字串、名稱、公告段落，以及書籤還缺幾條。
2. **列出要翻的**：在這個資料夾執行
   ```
   python tools\build_zh.py --todo
   ```
   會產生 `tools\todo.txt`，只有還沒翻的：
   - `編號<Tab>英文`：介面字串
   - `@英文名<Tab>`：名稱
   - `N編號<Tab>英文 markdown`：遊戲公告段落
3. **翻譯**：把譯文寫進 `tools\zh\` 的新檔案（例如 `ui_update_1110.txt`、`news_004.txt`），格式同上，Tab 分隔。
   - `{n}`、`{0}`、`<b>` 這類標記要原樣保留，對不上的會被擋下並列出。
   - 公告要保留 `**粗體**` 和 `` `程式碼` `` 的符號數量；**公告編號一定要有 N 開頭**（寫成純數字會蓋掉同號的介面字串）。
   - 修改過的字串（REPORT 的「內容改」）編號不變，直接在新檔案寫同一個編號的新譯文即可（後面的檔案優先）。
4. **合成書籤**：
   ```
   python tools\build_zh.py
   ```
   確認輸出是「介面字串 N/N、名稱 N/N、公告 N/N」都補滿、沒有 ⚠。
5. 書籤程式有改的話，把 `ro-zh.src.js` 開頭的 `VERSION` 加 1；只補翻譯可以不改版本號。
6. 推上 GitHub，線上書籤就會用新翻譯（使用者不用重新安裝書籤）。
