RO 倖存者離線版 非官方・v1.5

在自己的電腦開 RO Survivors 的小工具。官網維修、連線不穩的時候可以先玩玩看。

⚠ 先看這裡：離線版不會連到官方伺服器。不能登入帳號、不能雲端存檔、沒有廣場和排行榜， 進度不會同步到你的官方帳號。正式遊玩請到官網 ro-survivors.com。

使用步驟

  1. 安裝 Python 3（只要裝一次）：照下面的安裝教學做。
  2. 下載離線版，解壓縮到任何資料夾（例如桌面）。不要直接在壓縮檔裡面執行。
    ⬇ 下載離線版（zip，約 40 KB）
  3. 雙擊「開始遊戲.bat」。第一次會從官網下載遊戲（約 50 MB，大約 3 分鐘），完成後自動用瀏覽器開遊戲。
  4. 玩的時候黑色視窗要開著；玩完直接關掉黑色視窗就好。

之後每次開啟都會自動檢查兩件事，有新版就自動更新；沒有網路時直接用上次的版本：

  • 遊戲本身：官網有沒有新版本。
  • 離線工具：這個網頁有沒有新版的離線工具（主程式、GM 模式）。舊檔會備份在 _backup 資料夾。 只有「開始遊戲.bat」這類啟動檔有新版時，會提醒你回到這裡重新下載 zip。

無盡之塔與隱藏職業

  • 無盡之塔：正式版要登入帳號才能玩，離線版改用遊戲內建的本機模式，訪客角色也能玩。 進塔條件和正式版一樣：角色要二轉，並打倒關卡的 MVP 來開放樓層。到普隆德拉的「塔之守護者」那裡進入。 最高樓層、塔的點數、強化都記在離線存檔裡；過第 50 層一樣會解鎖染色「血腥狂暴（Blood Savage）」。 因為沒有伺服器，不會上排行榜，也不能中途存檔下次繼續。
  • 隱藏職業：正式版要找到「秘密」才能解鎖的忍者、槍手，離線版建立角色時直接可以選。

中文名稱

  • 遊戲已經內建繁體中文，但裝備、卡片、怪物名稱和少數技能名還是英文。離線版會自動換成台版譯名（例如 Katana → 太刀、Poring → 波利）， 裝備字尾也會改成中文語序（「太刀 of Strength」→「力量之太刀」）。
  • 只有遊戲語言選繁體中文時才會顯示；切成 English／Español 就是原文。
  • 圖書館員的百科搜尋可以直接打中文名稱；GM 模式的創造搜尋中文、英文都找得到。
  • 遊戲更新後新出現的裝備會先顯示英文，補上翻譯後離線工具會自動更新。

GM 模式

雙擊「以GM模式開始遊戲.bat」，遊戲流程跟一般模式一樣，另外多了這些功能：

在哪裡可以做什麼
角色視窗（C）→ 物品欄的「＋ 創造」創造任何裝備，可以選等階（1～3）、品質（普通～傳說）、精煉 +0～+10、數量，並即時顯示這件裝備的攻擊力／防禦力。附加能力由遊戲依等階和品質自動產生
角色視窗（C）→ 卡片的「＋ 創造」創造任何卡片，再用遊戲內的鑲嵌功能裝上
右下角紅色「GM」按鈕修改 Base Lv、職業 Lv、六項素質（每項 1～99，可以超過正常可分配的點數）、卡普拉點數
遊戲局中按「GM」修改這一局的金幣（zeny），馬上生效
  • 改裝備、卡片、等級、素質、點數時，頁面會自動重新載入並回到你的角色，大約 3 秒。
  • 遊戲局進行中只能改金幣；其他修改請先結束這一局、回到城鎮再改。
  • GM 模式的存檔和一般模式分開（網址 http://127.0.0.1:8382/），一般模式的角色不會被影響，也看不到 GM 模式的角色。
  • 一般模式和 GM 模式不要同時開。

安裝 Python 3

  1. 打開 Python 官網下載頁，按黃色的「Download Python 3.x.x」按鈕。
    開啟 python.org 下載頁
  2. 執行下載的安裝檔（檔名像 python-3.x.x-amd64.exe）。
  3. 安裝畫面最下面，一定要勾選「Add python.exe to PATH」，再按「Install Now」。
  4. 出現「Setup was successful」就裝好了，按 Close 關掉。
  5. 回到離線版資料夾，雙擊「開始遊戲.bat」。
想確認有沒有裝好？ 按 Win + R，輸入 cmd 按 Enter，在黑色視窗輸入： 
py --version
看到 Python 3.x.x 就是裝好了。
  1. 按開始功能表，打開「Microsoft Store」。
  2. 搜尋「Python 3」，選發行者是 Python Software Foundation 的最新版本（例如 Python 3.13）。
  3. 按「取得」或「安裝」，等它裝好。
  4. 回到離線版資料夾，雙擊「開始遊戲.bat」。

Store 版不用勾選 PATH，比較簡單；兩種裝法擇一即可。

  1. 到 python.org 下載頁下載 macOS 版，照畫面安裝。
  2. 「開始遊戲.bat」是 Windows 用的。Mac 請打開「終端機」，輸入 cd （後面有空白），把離線版資料夾拖進終端機視窗，按 Enter。
  3. 再輸入下面這行，按 Enter： 
    python3 rs_offline.py

常見問題

雙擊後出現「Windows 已保護您的電腦」 這是 Windows 對網路下載的檔案的一般提醒。按「其他資訊」→「仍要執行」即可。 不放心的話，可以先用記事本打開 開始遊戲.bat、rs_offline.py、gm.js 檢查內容，全部都是純文字。
黑色視窗說找不到 Python，然後打開這個網頁 代表 Python 還沒裝好，或安裝時沒勾「Add python.exe to PATH」。 重新執行 Python 安裝檔，選「Modify」或直接重裝並勾選 PATH；或改用 Microsoft Store 版。裝好後要重新雙擊「開始遊戲.bat」。
我的角色不見了 離線版的進度存在瀏覽器裡，網址是 http://127.0.0.1:8381/。以下情況會看不到： 換了另一個瀏覽器、清除了瀏覽器的網站資料、或用無痕視窗。 另外，如果黑色視窗顯示 8381 被占用、改用別的號碼，也會看不到之前的進度，把其他離線版視窗關掉再開就好。
畫面圖片怪怪的、缺圖 打開離線版資料夾，在檔案總管上方的網址列輸入 cmd 按 Enter，然後輸入下面這行，會把圖片音效全部重新下載： 
py rs_offline.py --refresh-assets
也可以直接刪掉 cache 資料夾，下次開啟會重新下載。
會不會被封帳號？ 離線版完全不會連到官方的帳號伺服器，也不會上傳任何東西，跟你的官方帳號沒有關係。 但離線版的進度也沒辦法帶到官網。
要佔多少空間？ 遊戲程式約 4 MB，圖片音效約 50 MB。不想玩了直接把整個資料夾刪掉即可，不會留下其他東西（瀏覽器裡的進度除外）。

安全性

  • 程式只連到兩個地方：ro-survivors.com（下載遊戲檔案）和這個網頁所在的 jtnhrbpvvm-spec.github.io（檢查離線工具的新版），不會上傳任何東西。
  • 離線工具自動更新時，每個檔案都會先比對指紋（SHA-256），對不上就不更新；舊檔備份在 _backup。
  • 本機伺服器只綁在 127.0.0.1，只有你自己的電腦連得到，區域網路的其他人連不到。
  • 只用 Python 內建功能，不用安裝其他套件；程式碼完全公開，可以用記事本打開檢查。

本工具為玩家自製，與官方無關，不包含任何遊戲檔案；遊戲檔案都是執行時從官網下載到你自己的電腦。 遊戲內容版權屬於 RO Survivors（作者 Reven4nt）與 Gravity。請支持官方。
