👤 基本資料
名稱、等級、經驗值、金錢、HP、職業、轉職進度、名聲、遊玩時間。這些欄位直接對照你上傳的存檔格式，可以放心編輯。
📊 屬性點數
力量 / 敏捷 / 智力 / 體力 / 精神 / 幸運，六圍基礎值。
🛡️ 裝備欄位
裝備欄位存的是「背包物品的 Stack ID」，不是物品 ID。要讓某個欄位生效，請先到「🎒 背包」加入該裝備物品， 再把它在背包表格裡的 Stack ID 填到對應欄位。
🎒 背包
stacks：每一列是一疊物品，包含物品、數量、與獨立的 Stack ID。裝備欄位會透過 Stack ID 指向這裡的某一列。是裝備的物品會多顯示「精煉」下拉選單（+0~+12 固定選項），非裝備物品顯示「-」。
物品數量精煉Stack ID
🏦 倉庫
倉庫是所有角色共用的儲物空間，跟角色背包分開存放。
物品數量精煉Stack ID
✨ 已學技能
點選要新增/移除的技能，右邊數字是技能等級（存檔真實格式已驗證為 [[技能ID, 等級], ...]）。
🌟 輔助狀態
buffSkillIds 存的是「目前啟用」的輔助技能 ID 清單。實際持續時間 (durMs) 是技能本身的資料， 跟著該技能在「✨ 已學技能」裡的等級變化——所以下面「套用等級」是讓你一次調整所有輔助技能的等級， 藉此改變它們的持續時間；存檔本身沒有另外獨立的「持續時間」欄位可以直接設定。

🐾 寵物
⚠️ 遊戲同時間只能有 1 隻寵物「出戰中」，其他都只是閒置庫存，不會提供任何加成！
寵物可以同時擁有很多隻（像倉庫），用最左邊的圓點選擇要出戰的那隻。 uid（流水號）、id（寵物種類）、grow（成長階段）、exp（經驗）、hunger（飽食度）。 寵物綁定名聲系統：角色名聲必須達到「所需名聲」（唯讀欄位，來自寵物基礎資料）才能讓該寵物出戰， 不夠的話遊戲裡就不會顯示出戰按鈕——已實測確認 grow 等級跟出戰無關，所以新增寵物的 grow/exp/hunger 預設為 0 即可。

🧪 藥水自動使用設定
離線 / 掛機時自動喝藥的閾值與藥水種類。
📖 物品紀錄
已見過的物品（圖鑑用）與正在追蹤掉落數量的物品。
📍 目前位置
角色目前所在地圖與座標、正在打的怪物 / 採集點 ID。
🔧 進階欄位 格式為推測值
以下欄位的格式已透過一份真實的滿等存檔驗證過（不再是憑空猜測），但因為內部結構比較複雜（陣列包陣列、物件包物件）， 暫時還是用原始 JSON 呈現，還沒做成表單。修改前建議先備份存檔。
🔁 轉移碼
跟遊戲內建的轉移碼是同一套機制：把存檔暫存到 Litterbox（catbox.moe 的臨時檔案服務）， 換一組短碼帶著走。72 小時後檔案會自動刪除，短碼本身不會過期以外的時間保存資料。
