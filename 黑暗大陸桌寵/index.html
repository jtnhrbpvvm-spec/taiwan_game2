黑暗大陸桌寵

遊戲在背景照常掛機，畫面上留你的角色走來走去。
一隻桌寵一個帳號，可以同時掛好幾個帳號。

下載安裝檔

版本 1.3.0・約 79 MB・Windows 10／11（64 位元）

下載安卓版

版本 1.2.0・約 1.7 MB・Android 8 以上

iPhone 和 iPad 目前不支援。桌寵只有 Windows 電腦版和安卓手機版。

桌面底部示意

能做什麼

背景掛機遊戲藏在背景照常打怪，不用開瀏覽器；要操作時對桌寵點兩下叫出來。
多帳號同時掛幾隻桌寵就是幾個獨立的遊戲，每隻掛一個帳號，登入、存檔互不影響。
一鍵登入帳號密碼記在帳號檔（加密存放），右鍵點一下就自動登入、繼續冒險。
進帳看得到經驗、金幣、掉寶從那隻桌寵頭上飄出來，升級時會跳起來施法。
自動更新桌寵自己會下載新版；遊戲改版時也會提醒你套用。
勿擾模式專注模式下桌寵變半透明、不擋滑鼠，也不跳提醒。
收入總覽這次打開以來每隻賺了多少：經驗、金幣、打怪數、拿到和自動賣出的東西；還有目前地圖的怪物分布和可獲得物品。
跟著變身角色讀變形卷軸變身時，桌寵也換成變身的樣子；也能選變身外觀固定。

安裝

  1. 按上面的「下載安裝檔」，檔案會直接從 GitHub 下載（約 79 MB）。
  2. 雙擊下載回來的 dark-continent-pet-setup-x.x.x.exe。
  3. Windows 會跳出藍色的「Windows 已保護您的電腦」。這是因為安裝檔沒有購買數位簽章，不是中毒。
    按 其他資訊 → 仍要執行。
  4. 照安裝畫面按下一步。裝好後桌面和開始功能表會多一個「黑暗大陸桌寵」的捷徑。

裝之前先知道

  • 同一個帳號不要同時在瀏覽器或手機上玩。遊戲同一個帳號只能在一個地方上線，兩邊會互相踢掉。
  • 需要網路。桌寵裡跑的就是線上版遊戲，遊戲改版會提醒你套用。
  • 只支援 Windows 電腦，手機和 Mac 不能用。
  • 每多一隻桌寵就多跑一個遊戲，大約多佔 300～500 MB 記憶體。電腦比較舊的話，先從一兩隻開始。
  • 解除安裝從 Windows「設定 → 應用程式」移除即可。角色都在雲端，帳號檔留在電腦裡。

第一次使用

  1. 第一次啟動會跳出操作說明，桌面底部出現一隻桌寵。
  2. 對桌寵按右鍵 → 帳號管理…，填入遊戲帳號的 Email 和密碼，按「儲存」。有幾個帳號就加幾個，名稱可以自己取（例如：主帳、法師小號）。
  3. 在同一個視窗上面的「每隻桌寵用哪個帳號」選好帳號。桌寵會自動登入、下載雲端角色、按「繼續冒險」開始掛機。
  4. 要掛更多帳號：右鍵 → 桌寵數量 選幾隻，再到「帳號管理…」或對那一隻按右鍵 → 帳號（第 N 隻） 選帳號。
  5. 角色如果停在村莊裡沒有打怪，對那隻點兩下叫出遊戲，出發一次就好。之後把遊戲視窗關掉，它會藏起來繼續掛機。

沒有帳號也能玩：選「訪客（不登入）」，存檔只在那隻桌寵自己的遊戲裡。

帳號檔

帳號存在 %APPDATA%\黑暗大陸桌寵\accounts.json，「帳號管理…」視窗裡有按鈕可以直接打開資料夾。

  • 密碼用 Windows 內建的加密存放，只有這台電腦、這個 Windows 使用者解得開，檔案被複製走也讀不出密碼。
  • 想一次加很多帳號，可以直接編輯檔案，每個帳號寫成 { "label": "小號", "email": "…", "password": "…" }。下次打開桌寵會自動把密碼轉成加密、明文刪掉。
  • 換電腦或重灌後密碼解不開，到「帳號管理…」重新輸入即可。

桌寵頭上冒出來的東西

飄上去的小字這段時間拿到的經驗、金幣和留在背包裡的掉寶。遊戲大約 20 秒存檔一次，所以是一批一批出現；被自動賣掉的不會顯示
對話框只有更新提醒：「黑暗大陸更新了」或「桌寵有新版本」。勿擾模式時不跳，解除後才補講

更新

  • 桌寵：打開時和之後每 30 分鐘檢查一次，有新版會在背景下載，好了會提醒你。右鍵最上面按「立即更新桌寵」重新啟動安裝；不按的話，下次結束桌寵時自動裝好。
  • 遊戲：每 30 分鐘比對線上遊戲的版本，改版時提醒你，右鍵最上面按「套用遊戲更新」把全部遊戲重新載入成新版。建議套用，舊版遊戲有可能沒辦法上傳雲端進度。

常見問題

打開遊戲時左下角的訊息框一直開著

這是收入總覽要用的：遊戲只把「自動賣出了什麼」寫在訊息框的「掉落紀錄」裡，遊戲藏著時桌寵會把它打開來抄。可以自己關掉，下次藏起來時桌寵會再打開。

登入失敗

桌寵頭上會飄出原因，那隻的遊戲視窗也會自己打開。通常是密碼打錯：到「帳號管理…」按那個帳號的「修改」重新輸入密碼。也確認同一個帳號沒有在別的地方上線。

開了專注模式之後點不到桌寵

三種方法都可以解除：按 Ctrl Alt P、按住 Ctrl 再對桌寵按右鍵、或再點一次桌面上的捷徑。

找不到桌寵

再點一次桌面捷徑，桌寵和第 1 隻的遊戲視窗都會被叫出來。也可以從畫面右下角系統匣的圖示操作。

角色沒有在打怪

對那隻點兩下把遊戲叫出來看一下，通常是角色人在村莊，出發就好。

快捷鍵沒反應

可能被別的程式佔用了。改用對桌寵點兩下、右鍵選單，或系統匣的圖示。

電腦變慢

每隻桌寵都是一個完整的遊戲在跑。右鍵 →「桌寵數量」減少幾隻，多出來的遊戲會馬上關掉。

安裝

  1. 按上面的「下載安卓版」，下載完點開那個 APK 檔。
  2. 手機會問要不要允許「安裝未知來源的應用程式」，選允許，再按安裝。
  3. 打開 App，照畫面指示開啟「顯示在其他應用程式上層」的權限（有些手機叫「浮動視窗」「懸浮視窗」），桌寵就會出現。

開權限時出現「應用程式存取權已遭拒絕」

這是安卓對「不是從商店安裝的 App」多加的一道保護，新款手機都會遇到。要先手動解除一次：

  1. 先按「關閉」。
  2. 回到桌寵的畫面，按「打開應用程式資訊」（或到手機的「設定 → 應用程式 → 黑暗大陸桌寵」）。
  3. 按畫面右上角的「⋮」（三個點），選「允許受限制的設定」，照手機的指示驗證。
  4. 回到桌寵，再按一次「前往開啟權限」，這次就可以把開關打開了。

要先看過一次「已遭拒絕」的訊息，「允許受限制的設定」那個選項才會出現。

第一次使用

  1. 長按桌寵打開設定，到「帳號」分頁填入遊戲帳號的 Email 和密碼，按「儲存」。
  2. 到「桌寵」分頁選這隻要用的帳號。桌寵會自動登入、下載雲端角色、按「繼續冒險」開始掛機。
  3. 要掛第 2 個帳號：「設定」分頁的「桌寵數量」選 2 隻，再到「桌寵」分頁切到第 2 隻選帳號。

手機效能有限，建議 2 隻、最多 3 隻。開太多的話遊戲可能被系統放慢，變成離線收益的狀態（掛機效率變差、要扣鑽石結算）。選第 3 隻時會先跳說明，按「我了解」才會開。

沒有帳號也能玩：帳號選「訪客」，存檔只在那隻桌寵自己的遊戲裡。

更新

  • 桌寵每 30 分鐘檢查一次遊戲和桌寵有沒有新版。小更新自己下載，下次啟動生效。
  • App 有新版時桌寵會提醒，長按桌寵到設定裡按「下載並安裝」，裝完記得按「開啟」。
  • 遊戲改版時桌寵會提醒，到設定裡按「套用遊戲更新」重新載入。
  • 專注（勿擾）模式時不跳提醒，解除後才補講。

裝之前先知道

  • 同一個帳號不要同時在瀏覽器或電腦版上玩，會互相踢掉。
  • 為了讓螢幕關掉後繼續掛機，手機不會進入深度待機，會比平常耗電。
  • 有些品牌的手機（小米、OPPO、vivo、三星等）會自動關掉背景的 App。掛機中斷的話，到手機設定把這個 App 的電池用量改成「不受限制」，並允許自動啟動。
  • 安卓版目前只在模擬器上測過，遇到問題請告訴作者。
