黑暗大陸桌寵

需要一個權限

桌寵要顯示在其他 App 上面，請開啟「顯示在其他應用程式上層」（有些手機叫「浮動視窗」「懸浮視窗」）。按下面的按鈕會帶你到設定頁，把開關打開後回到這裡。

出現「應用程式存取權已遭拒絕」的話

這是安卓對「不是從商店安裝的 App」多加的一道保護，要先手動解除一次：

  1. 先按「關閉」。
  2. 按下面的「打開應用程式資訊」。
  3. 按畫面右上角的「⋮」（三個點），選「允許受限制的設定」，照手機的指示驗證。
  4. 回到這裡，再按一次上面的「前往開啟權限」。

找不到「⋮」的話：到手機的「設定 → 應用程式 → 黑暗大陸桌寵」，在那個畫面的右上角。要先看過一次「已遭拒絕」的訊息，那個選項才會出現。

桌寵有新版

按下面的按鈕下載，下載完會跳出系統的安裝畫面，再按一次「更新」。裝完請按「開啟」，桌寵才會回來（按到「完成」的話，自己再點一次桌寵的圖示就好）。帳號和設定都會保留。

黑暗大陸更新了

按下面的按鈕把全部遊戲重新載入成新版（會自動登入、繼續冒險）。建議套用，舊版遊戲有可能沒辦法上傳雲端進度。

怎麼用

遊戲會在背景繼續掛機，畫面上留你角色職業的小人。同一個帳號不要同時在瀏覽器或電腦版上玩，會互相踢掉。

點桌寵打開那一隻的遊戲。按上方的「收起」或返回鍵收回去
按住拖曳把桌寵移到別的位置
長按桌寵打開這個設定畫面
通知列顯示遊戲、設定、結束

第一次使用

到「帳號」分頁加入遊戲帳號（Email、密碼），再到「桌寵」分頁選這隻要用的帳號。桌寵會自動登入、下載雲端角色、按「繼續冒險」。

不登入也能玩：帳號選「訪客」，存檔只在這隻桌寵自己的遊戲裡。

好幾個帳號

「設定」分頁的「桌寵數量」選幾隻，就有幾個獨立的遊戲同時在背景跑，每隻掛一個帳號。

手機效能有限，建議 2 隻、最多 3 隻。開太多的話遊戲可能被系統放慢，變成離線收益的狀態。

要注意的事

為了讓螢幕關掉後繼續掛機，手機不會進入深度待機，會比平常耗電。

有些品牌的手機（小米、OPPO、vivo、三星等）會自動關掉背景的 App。遇到掛機中斷的話，到手機設定把這個 App 的電池用量改成「不受限制」，並允許自動啟動。

要開第 3 隻嗎？

每隻桌寵都是一個完整的遊戲在背景跑。手機效能有限，開太多的話遊戲可能被系統放慢，變成離線收益的狀態（掛機效率變差、要扣鑽石結算）。

建議 2 隻，最多 3 隻不同帳號。手機比較舊、或發現掛機變慢的話，請改回 2 隻。
