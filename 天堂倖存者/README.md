# 天堂倖存者下載工具與工具自動更新

需要 Node.js 18 以上，不需 npm install。Windows x64 玩家不必預先手動安裝：六個批次入口會先檢查 PATH 與常見安裝位置；找不到可用版本時，會執行同一資料夾隨附的 `node-v26.13.1-x64.msi`。請允許 Windows 管理員提示並等候安裝完成，啟動器會接著執行原本功能。取消或安裝失敗時會停止並顯示原因，不會繼續啟動。

打包給玩家時，請把上述 MSI 與啟動器一起保留。啟動器會驗證固定的 SHA-256，損壞或被替換的安裝包不會執行；不會自動下載安裝包。此 MSI 適用 Intel／AMD 64 位元 Windows；ARM64 或 32 位元系統須自行安裝相容的 Node.js。若 Windows 要求重新開機且尚無法使用 Node.js，重新開機後再啟動。

隨附檔案來源：使用者自 Node.js 官方下載的 Windows Installer，OpenJS Foundation 數位簽章驗證有效。MSI 只放在兩個工具資料夾根目錄，沒有放入 `updates/objects/`，工具自動更新不搬運安裝包。更換 MSI 版本時也必須更新啟動器內的檔名與雜湊。ZIP 是免安裝壓縮包，本次採用 MSI 安裝流程。

## 資料放置規則

- 遊戲網頁、程式、圖片、地圖、音樂與原始下載報告，一律保存在桌面「天堂倖存者/離線遊戲」。
- 本機 GitHub「taiwan_game2/天堂倖存者」只放自行製作的下載工具、離線化程式、測試、說明，以及工具更新必要的公鑰、簽章清單和小型封包。
- `updates/` 只發布工具程式，沒有原站遊戲檔案或素材。發布器使用明確的工具白名單，不會掃描或壓縮桌面的遊戲資料。
- 爬蟲禁止將下載輸出設在上述桌面資料夾以外的位置。從 GitHub 資料夾執行爬蟲也會存到桌面。
- 更新器不會在 Git 儲存庫內套用更新，避免覆寫尚未推送的工具修改；請使用桌面的啟動器。

## 遊玩與下載

1. 執行 `更新下載.bat`，向 https://l1stw.com/ 取得公開遊戲資源，並製作桌面離線版。執行 `重新補抓缺檔.bat` 可只重試缺少的候選資源。
2. 執行桌面「天堂倖存者/開啟離線版.bat」，在選擇視窗按「一般模式」或「GM 模式」。一般模式不顯示 GM 選單；GM 模式開啟管理控制台。關閉選擇視窗即取消，不會啟動安裝或更新。批次入口使用純 ASCII 指令及 Windows CRLF 換行；選擇後先檢查 Node.js，再檢查工具更新與原站遊戲腳本版本。原站版本改變時自動更新遊戲本體（已下載的素材沿用，只抓新增與變更的檔案；失敗時還原為更新前的版本），接著用桌面原始程式套用最新離線化邏輯、啟動本機伺服器。
3. 在遊戲中輸入本機帳號即可登入，不需要密碼。第一次使用的帳號會自動建立，再選擇或建立角色；輸入舊帳號可繼續原本的角色與進度，不同帳號的存檔分開保存。帳號格式為 2～14 個英文字母、數字或底線。結束時關閉分頁，並在伺服器視窗按 Ctrl+C。

請固定使用 `http://127.0.0.1:8379/` 和同一瀏覽器，才能讀取原本的本機存檔。不要直接開 HTML。首次開啟預設靜音，可在遊戲設定調整。

## GM 模式

執行桌面 `開啟離線版.bat`，按「GM 模式」，登入並選擇角色後點右下方「GM 控制」。新控制台只在選擇 GM 模式後出現，與一般模式共用同一瀏覽器的角色。舊的 `GM模式.bat` 保留相容用途，也會顯示相同的選擇視窗。切換模式前，請先關閉原本的分頁與伺服器視窗。

- 裝備／道具：搜尋目前遊戲內的道具、新增、調整數量與強化值、裝備或鎖定、刪除。職業限制與背包容量仍適用。
- 角色與資源：金幣、倖存者金幣、娃娃代幣、永久等級、成長生命與護盾、六項額外素質。
- 戰鬥輔助：回滿生命與護盾、本局生命與護盾、移速與傷害倍率、結算怪物、回村莊。倍率只在此次 GM 遊玩中有效；控制台開啟時暫停戰鬥。
- 備份還原：每次永久修改前自動保留目前角色最近 5 份備份，也可手動備份與還原。備份存於同一瀏覽器，清除網站資料會一併刪除。

控制台沒有無敵選項，也不會自動啟用無敵。工具更新套用後，重新套用離線化程式會自動建立 GM 啟動器。

選擇一般模式時，原站內建的 GM 測試選單、測試 NPC 與免費天賦點按鈕都不會顯示。兩種模式共用角色存檔，但排行榜分開保存。切換時先關閉原本的伺服器視窗，再開啟選擇視窗選擇另一模式。

## 離線 NPC 與紀錄

商店、武器與防具分類、隨機包及娜魯帕製作採用本機舊快取中保留的數值規則；不保證與原站目前伺服器價格、配方或獎勵一致。相容工具只攜帶必要的精簡數值設定，不發布整份原站程式或素材。購買、出售與隨機包會檢查金幣、背包與保存結果，失敗時回復交易；倉庫也檢查取回空間。

- 拍賣場顯示「拍賣場已關閉」，不提供交易。
- 只有王子／公主可花費 10,000 金幣創立本機血盟。其他帳號、角色可透過血盟 NPC 加入；支持退出、移出、轉讓盟主與解散。血盟資料共用於同一瀏覽器、相同本機網址。
- 本機每日任務固定為目前的 10 項，不隨機輪替；任務與全勤獎的金幣、倖存者金幣均調為原本的 10 倍。全部領完合計 410,000 金幣及 50 倖存者金幣。台灣時間午夜重置進度與領獎紀錄，各角色分開保存；更新不會清除當日已領取標記，也不會重複補發。啟動時不再檢查線上每日任務，固定任務無須連線取得。
- 活動 NPC 可進入本機無限刷怪塔與每日三場刷錢區。無限刷怪塔每場存活至少 60 秒會留下一份本機領獎紀錄，獎勵為 1 個倖存者金幣；此為離線規則。
- 本機排行榜分為最快通關、最佳戰績、最長存活及最多擊殺，每類最多 50 筆。通關時間由短到長；最佳戰績依通關、關卡、擊殺與時間排序。每場結束、回村或離開頁面時保存，點紀錄可看帳號、角色、日期及戰績；GM 練習另存。

骰子、賽狗、天賦、公告、傳送及圖鑑沿用本機流程。多人決鬥與其他玩家即時連線並不會由這些本機 NPC 功能恢復。

GitHub 自動更新只更新工具與離線化程式，不會從 GitHub 下載遊戲素材。遊戲本體由啟動時的原站版本檢查負責：原站改版時直接向原站取得新版程式與新增素材，先備份目前的程式檔，任何一步失敗都還原，保留舊版可玩，下次啟動再試。`更新下載.bat` 仍可手動執行完整下載。正式帳號、雲端角色、多人與拍賣等伺服器功能無法離線提供。

原站回覆 404 的檔案會標成待補，備註「該遊戲沒有此檔案，未來遊戲有更新啟動遊戲時會補上」，不會當成本機檔案損壞。原站版本不變時不反覆重抓上千個已知 404；版本更新後重試，原站真的提供該檔案時才會保存並移除待補紀錄。逾時或連線失敗會分開顯示，並於啟動時重試。沒有網路時仍可使用既有離線版。

若下載最後出現「離線商店安裝位置改變」，先執行 `檢查更新.bat` 取得新版工具，再執行 `開啟離線版.bat`。新版使用遊戲初始化位置安裝離線功能，支援原站移除 `__game` 除錯介面的程式。已保存的原始檔與素材會沿用；缺少下載報告時會重建本機紀錄，無須整包重抓。未來離線修補失敗，也會保存下載報告供恢復；修補完成前會明確標為失敗。

## 手動發布工具更新

更新來源已設定為 `jtnhrbpvvm-spec/taiwan_game2` 的 `main/天堂倖存者/updates/latest.json`。

1. 修改 GitHub 本機資料夾裡的工具程式。
2. 在該資料夾雙擊 `產生GitHub更新包.bat`，產生只含工具的簽章更新包。
3. 自行在 GitHub Desktop 檢查、Commit、Push。工具不會替你提交、推送、建立 Release 或發布網站。
4. 桌面啟動器下次開啟時驗證更新簽章與 SHA-256，下載需要的工具封包並更新。離線或驗證失敗時保留現有工具。

私鑰只在桌面「天堂倖存者/.publisher/update-private.pem」，不在儲存庫或更新包；請自行另行備份。`trusted-key.pem` 是可公開推送的驗證公鑰。

`檢查更新.bat` 會額外驗證並修復工具檔案。正在執行遊戲伺服器時不套用更新。暫存、版本紀錄及私鑰已加入忽略規則。私有 GitHub 儲存庫登入尚未支援，來源無法讀取時保留本機版。

舊的完整遊戲更新包已移到桌面備份，新更新器拒絕舊格式。若之前曾複製舊更新器到別處，請先手動覆蓋本次工具。

## 檢查

```powershell
node --test tests.cjs update-tests.cjs windows-launch-tests.cjs asset-recovery-tests.cjs gm-tests.cjs node-bootstrap-tests.cjs daily-check-tests.cjs mode-picker-tests.cjs source-compat-tests.cjs
node verify.cjs
node update_client.cjs --check
```

`verify.cjs` 檢查桌面遊戲資料；只有原站 404 待補時不回報本機損壞，已保存檔案真的遺失或損壞、或必要資源有其他下載錯誤時才回傳 2。測試報告、404 分析與 Chrome 截圖保存在桌面，不是工具更新內容。

AI 中繼資料存放在 `.ai-policy.json`，並保留於遊戲檔案的 ASCII 編碼註解；不會顯示於遊戲畫面。這是可解碼的資料，不是加密。
