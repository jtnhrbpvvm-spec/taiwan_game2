# 下載完成後無法啟動：原站新版相容修正

原站新版公開程式移除了 `window.__game` 除錯輸出，舊工具以它作為離線商店的安裝定位，因而在下載最後拋出「離線商店安裝位置改變」。截圖中的 404 待補不是這次致命錯誤的來源。

修正：商店、NPC 與 GM 改在遊戲初始化前安裝，不依賴除錯輸出；保留舊版相容與重複安裝保護。離線修補失敗時也會保存完整下載報告；對舊版已失敗、沒有下載報告的情況，啟動器會從 source、public 與下載進度檔重建本機紀錄，沿用已保存的素材。修補完成後清除失敗標記。

## 2026-11-19 原站 v1.1 補充修正

原站 v1.1 刪除了程式內的中文註解，舊工具靠註解定位，於是先後出現「LINE 連結區塊格式變更」和「原有 GM 選單格式改變」。改為以 `lineBtn` 及「GM測試」按鈕所在的頂層區塊定位，不再依賴註解；定位不唯一時仍會停止。已用原站 v1.1 完成離線轉換並開啟遊戲，沒有 JavaScript 錯誤，也沒有對外連線。

## 2026-11-19 啟動時自動更新遊戲本體、補抓漏掉的圖片

- 啟動時偵測到原站改版，會自動更新遊戲本體，不再只補抓缺檔。已有的素材沿用；更新前備份程式檔，失敗則還原，舊版仍可玩。

## 2026-11-19 改為登入後背景更新

開啟遊戲時不再等待網路更新。玩家登入後，本機伺服器在背景依序檢查工具更新與原站新版，新版慢慢下載到 `.pending-game`，下次開啟時套用，失敗會還原。離線化失敗時，啟動器會先更新工具再試一次。

## 玩家恢復步驟

1. 維護者先自行提交、推送這次工具及 updates 變更。
2. 玩家關閉錯誤視窗，執行「檢查更新.bat」。
3. 更新完成後執行「開啟離線版.bat」，選擇模式並等待重建下載紀錄與套用修補。
4. 保留既有「離線遊戲」資料夾，不需刪掉或整包重新下載。原始核心腳本確實缺少時，才按提示執行「更新下載.bat」，其餘已保存素材仍會沿用。
