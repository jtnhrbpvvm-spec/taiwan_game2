# 啟動器模式選擇

雙擊 `開啟離線版.bat` 會先出現 Windows 視窗，只有「一般模式」與「GM 模式」兩個按鈕。一般模式不顯示 GM 選單；GM 模式保留管理功能。Enter 預設一般模式，關閉視窗即取消，不開始 Node 安裝、工具更新或遊戲。兩種模式共用既有本機角色，排行榜仍分開。

舊 `GM模式.bat` 保留相容用途，但也開啟相同選擇視窗，不會直接啟動 GM。沒有搬移或刪除使用者檔案。

推送後第一次以舊版啟動器開啟會先取得更新；請關閉遊戲與伺服器，再次執行 `開啟離線版.bat` 即可看到新視窗。切換模式前同樣先關閉舊分頁與伺服器。
