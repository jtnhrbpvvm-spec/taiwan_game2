# 離線 NPC 與模式隔離更新

原站前端移除了價目、裝備分類與製作配方，這些介面仍要求伺服器查詢，造成「尚未連線」。更新以本機舊快取保留的精簡數值設定恢復交易；不保證與原站目前伺服器規則一致，沒有把整份原站程式或素材放入更新包。

- 商店買賣、裝備分類／詳細購買、隨機包、娜魯帕製作可離線使用。
- 補上背包容量、金幣不足、重複事件、存檔失敗回復與中斷交易的啟動回復；倉庫取出不再忽略容量。
- 拍賣 NPC 直接顯示「拍賣場已關閉」。
- 只有王子／公主能花費 10,000 金幣創立本機血盟；同一瀏覽器其他帳號、角色可透過 NPC 加入、退出，盟主可移出、轉讓與解散。
- 原站公開程式已實際檢查：每日任務清單仍要求正式登入後取得。啟動器每次檢查公開程式的可取得性，但不會把本機任務宣稱為同步原站任務。離線提供獨立的 10 項任務，依角色保存、台灣午夜重置，防止重複領獎。
- 活動改成本機挑戰及領獎。骰子、賽狗、公告、天賦、傳送與圖鑑保留本機流程。多人決鬥沒有轉成多人連線服務。
- 每場結束、回村或離開頁面時建立戰局紀錄；最快通關、最佳戰績、最長存活、最多擊殺各保留最佳 50 筆。可點擊查看角色、帳號、日期與戰績。GM 紀錄另存。
- 一般模式不建立原站 GM 測試選單，也不顯示新增的 GM 控制台、測試 NPC 或免費天賦點；只有 GM 啟動器會開啟這些入口。

驗證：29 項自動測試通過，靜音 Chrome 完成商店、製作、倉庫、骰子／賽狗、同帳號不同角色及跨帳號血盟、每日任務與重複領獎、55 場排行榜排序／截斷、一般及 GM 模式隔離、中斷交易回復。測試遊戲沒有遠端請求、後端 API 請求或 JavaScript 執行錯誤；瀏覽器與測試伺服器已關閉。
