上傳你的 idle-seal 存檔檔案，接著從左側選單挑選要編輯的項目。所有處理都在瀏覽器本機進行，不會上傳到任何伺服器。

這個修改器能做到的事
👤 基本資料
名稱、等級、經驗值、金錢、HP、職業、轉職進度、名聲、遊玩時間。這些欄位直接對照你上傳的存檔格式，可以放心編輯。
📊 屬性點數
力量 / 敏捷 / 智力 / 體力 / 精神 / 幸運，六圍基礎值。
🛡️ 裝備欄位
下拉選單會顯示「目前裝備」的物品；如果這個欄位還沒裝備東西，才會改顯示「從背包選擇」讓你挑背包裡符合條件的裝備。 選「－ 卸下這個欄位」可以清空目前的裝備。中間的 +0~+12 是精煉值，會直接改到裝備所在那疊物品的 refine（跟背包表格是同一份資料，改這裡背包也會一起更新）。
點選某個裝備欄位的下拉選單，這裡會顯示該裝備的詳細能力。
🔮 附魔
對照真實存檔驗證：裝備的附魔存在該物品所在那疊 stack 的 options 欄位，格式是 {grade, options:[{kind,value,unit},...]}，最多 3 條屬性。 先選部位、再選背包裡符合這個部位的裝備（不限職業/等級，方便你先附魔好再穿），下面就能編輯它的附魔內容。 數值欄位旁邊的範圍是該等級這個屬性實際可能開出的數值區間（依真實機率表算出來的）， 僅供參考，不會幫你卡住輸入範圍，超過多少都能填。
🎒 背包
stacks：每一列是一疊物品，包含物品、數量、與獨立的 Stack ID。裝備欄位會透過 Stack ID 指向這裡的某一列。是裝備的物品會多顯示「精煉」下拉選單（+0~+12 固定選項），非裝備物品顯示「-」。物品欄不能手動輸入更改，要新增物品請用下面的搜尋框，必須是遊戲裡真的存在的物品才能新增。點選物品名稱可以在下面看到詳細能力／介紹。
點選下方任一件物品的名稱，這裡會顯示詳細能力／介紹。

點選下方任一件物品的名稱，這裡會顯示詳細能力／介紹。

✨ 已學技能
點選要新增/移除的技能，右邊數字是技能等級（存檔真實格式已驗證為 [[技能ID, 等級], ...]）。
🌟 輔助狀態
buffSkillIds 存的是「目前啟用」的輔助技能 ID 清單。實際持續時間 (durMs) 是技能本身的資料， 跟著該技能在「✨ 已學技能」裡的等級變化——所以下面「套用等級」是讓你一次調整所有輔助技能的等級， 藉此改變它們的持續時間；存檔本身沒有另外獨立的「持續時間」欄位可以直接設定。

🐾 寵物
⚠️ 遊戲同時間只能有 1 隻寵物「出戰中」，其他都只是閒置庫存，不會提供任何加成！
寵物可以同時擁有很多隻（像倉庫），用最左邊的圓點選擇要出戰的那隻。 uid（流水號）、id（寵物種類）、grow（成長階段）、exp（經驗）、hunger（飽食度）。 寵物出戰有兩道門檻：角色等級要達到「所需等級」、名聲要達到「所需名聲」（都是唯讀欄位，來自寵物基礎資料）， 兩個都不夠的話遊戲裡就不會顯示出戰按鈕。grow 最低要是 1：屬性加成表只有 9 格（對應 grow 1~9）， grow:0 查不到資料會顯示「無任何能力」，所以新增寵物預設 grow 是 1。

🌠 個性化
對照真實存檔驗證：stage（階段）決定同時「展現」幾條屬性（超過上限的會顯示「尚未生效」，跟遊戲畫面一致）。 升到下一階需要角色等級達到門檻，這裡僅顯示參考資訊，不會幫你檢查。 屬性的實際數值由遊戲另外計算（跟這裡看到的原始數字不同，例如選 S 我們填 1600，遊戲實際顯示 1598）， 所以數值欄位不開放編輯，只給你選 B / A / S 等級，數值交給選單自動帶入。

📜 任務
任務本身沒有文字標題（遊戲資料只有數值），下面用「地點 → 委託名稱 → 任務內容」三層下拉選單幫你縮小範圍找到要的任務。 任一層留空（選「無」）就視為那一層全選、不篩選。找到任務後，用下面的核取方塊決定它現在算不算在 activeQuests 清單裡（對照真實存檔驗證過，格式是任務 ID 陣列）。 「目前進度」是拿角色背包裡實際持有的繳交物品數量，即時跟需求數量比對算出來的（不是存檔裡另外存的欄位）。

🎯 討伐任務
跟上面的「任務」是完全不同的另一套系統（討伐指定怪物 N 隻換獎勵）。不用找 NPC 接取—— 實測確認是角色等級到達解鎖等級、又打了指定怪物，就會自動開始計算進度。 完成狀態欄位 missionsDone、進度欄位 missionKills 都已由真實存檔驗證： 前者是任務 ID 陣列，後者是 [[任務ID, 目前擊殺數], ...]，兩個都可以直接編輯。
目前已完成的討伐任務
👥 隊伍
對照真實存檔驗證：party 存的是隊友「快照」的副本（跟角色自己的 snapshot 欄位結構一樣）， 用 sourceId 對應到另一個角色的 id。組隊在存檔層面，就是把對方角色自己當下的 snapshot 整包複製一份塞進這裡。加入隊伍後，如果對方之後升級/改裝備，這裡的副本不會自動更新， 要重新「加入隊伍」一次覆蓋成最新的才會同步。
🔧 進階欄位 格式為推測值
以下欄位的格式已透過一份真實的滿等存檔驗證過（不再是憑空猜測），但因為內部結構比較複雜（陣列包陣列、物件包物件）， 暫時還是用原始 JSON 呈現，還沒做成表單。修改前建議先備份存檔。
🔁 轉移碼
跟遊戲內建的轉移碼是同一套機制：把存檔暫存到 Litterbox（catbox.moe 的臨時檔案服務）， 換一組短碼帶著走。72 小時後檔案會自動刪除，短碼本身不會過期以外的時間保存資料。
