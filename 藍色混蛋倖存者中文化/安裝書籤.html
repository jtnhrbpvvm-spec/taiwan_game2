安裝書籤

藍色混蛋 繁體中文
▲ 把這顆按鈕「拖曳」到書籤列（直接點不會有作用）
  1. 按 Ctrl + Shift + B 打開瀏覽器的書籤列。
  2. 把上面的按鈕拖曳到書籤列上，就完成了。
  3. 或是：Chrome 設定 → 匯入書籤和設定 → 選「書籤 HTML 檔案」→ 選同一個資料夾裡的 書籤匯入檔.html。
手機怎麼裝？（複製網址）
  1. 按下面的按鈕複製書籤內容。
  2. 隨便把一個網頁加入書籤，再編輯那個書籤，把「網址」整個換成剛剛複製的內容，名稱改成「藍色混蛋 繁體中文」。
  3. 打開遊戲頁面後，在網址列輸入書籤名稱，從清單點它（手機瀏覽器從書籤選單點，有時不會執行）。

開始遊戲

  1. 打開遊戲頁面，等它載入。
  2. 點書籤，遊戲會自動重新載入一次（要再下載遊戲資料，約幾十秒，載入畫面會顯示進度）。
  3. 點一下畫面，選單就是繁體中文了。
  4. 之後每次打開或重新整理遊戲頁面，都要再點一次書籤。

注意事項

  • 畫面變成韓文？沒點書籤時遊戲會是韓文，因為存檔的語言被設成「繁中模式」。點一次書籤就回到中文。想看原版英文，到 設定 → 遊戲 → 變更語言。
  • 遊戲內 設定 → 遊戲 → 變更語言 可以切換 繁體中文／English。
  • 進度存檔不會動到，只改了存檔裡的語言設定，也不會上傳任何資料。
  • 計時器、Dash [Space]、LEVEL UP 這類 HUD 文字和美術字，是遊戲的點陣字或圖片，維持英文。
  • 只支援網頁版，下載版 RockmanXSurvivors.exe 不能用書籤。
  • 遊戲更新後，如果按書籤跳出錯誤、或出現方塊和空白，代表要等中文化更新。
