# 深空當舖攻略 — 記憶檔

《深空當舖：可能是偷的》（英文 Probably Stolen，簡中「深空当铺可能是偷的」）賺錢流派攻略。
純靜態網頁，直接雙擊 `index.html` 或放 GitHub Pages 都能看。

## 檔案結構

```
深空當舖攻略/
├─ index.html              整合閱讀頁（總覽卡片、搜尋、分類篩選、比較表、各流派內頁）
├─ 記憶檔.md               就是這份
├─ CLAUDE.md               給 Claude 的指標，內容指向這份記憶檔
└─ strategies/
   ├─ manifest.js          流派清單（載入順序）← 新增流派一定要改這裡
   ├─ _template.js         新流派範本（不會被載入）
   ├─ 00-basics.js         共通基礎：房租、買斷、房貸、開局身分、王爾德解鎖價、成就
   ├─ 01-trading.js        倒賣流
   ├─ 02-water.js          賣水流
   ├─ 03-wine.js           釀酒流
   ├─ 04-rats.js           養鼠流
   ├─ 05-aquafarm.js       養魚流
   ├─ 06-hydroponics.js    水耕流（含植物基因）
   ├─ 07-smelting.js       冶金流（熔爐＋電池充電）
   ├─ 08-chemistry.js      化學流（純度、回頭客、毒性）
   ├─ 09-gunsmith.js       軍火流
   ├─ 10-fence.js          銷贓流
   ├─ 11-appraisal.js      鑑定流（假菸、貼標、估價委員會）
   ├─ 12-bounty.js         賞金流（通緝犯、改造體）
   └─ 13-scavenge.js       拾荒流（含一貧如洗／困難開局）
```

## 新增一個流派（3 步）

1. 複製 `strategies/_template.js` → `strategies/NN-英文名.js`（NN 接著編號，例 `14-vending.js`）。
2. 改內容：`id` 不能和別人重複、`order` 決定排序、`group` 用 `基礎 / 買賣 / 生產 / 灰色 / 黑色` 其中一個。
3. 把檔名加進 `strategies/manifest.js` 的陣列。

完成。`index.html` 不用改，會自動出現在卡片、比較表、搜尋裡。網址 `index.html#英文id` 可直接打開那篇。

## 資料格式

每個檔案做一件事：`window.PS_STRATEGIES.push({ ... })`。欄位：

| 欄位 | 說明 |
|---|---|
| `id` | 英文代號（網址用） |
| `order` | 數字，排序 |
| `icon` | 一個 emoji |
| `name` / `tagline` | 名稱 / 一句話介紹 |
| `group` | 分類（新分類要順便加到 index.html 的 `GROUPS` 和 CSS `--g-分類名` 顏色） |
| `stats` | `{capital, difficulty, risk, speed}` 各 1～5：起手資金、上手難度、風險、回本速度（越大越快） |
| `unlock` | 解鎖方式 |
| `tags` | 標籤陣列（點了會搜尋） |
| `sections` | 段落陣列，每段可有 `title`、`p`（字串或陣列）、`steps`（編號清單）、`list`、`table: {head, rows}`、`note`（黃框） |
| `tips` / `pitfalls` | 小技巧 / 地雷 |
| `sources` | `[{title, url}]` 資料來源 |
| `updated` | 最後更新日期 |

文字裡可用簡單 HTML（`<b>`、`<i>`、`<code>`）。字串裡有單引號要寫 `\'`。
改完可以用這行檢查語法：`for f in strategies/*.js; do node -e "global.window={};require('./$f')" || echo "壞掉: $f"; done`

## 更新既有流派

直接改對應的 js 檔，記得改 `updated` 日期，新來源加進 `sources`。
