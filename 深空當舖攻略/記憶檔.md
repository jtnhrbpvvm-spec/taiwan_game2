# 深空當舖攻略 — 記憶檔

《深空當舖：可能是偷的》（英文 Probably Stolen，簡中「深空当铺可能是偷的」）賺錢流派攻略。
純靜態網頁，直接雙擊 `index.html` 或放 GitHub Pages 都能看。

## 檔案結構（2026-11-03 起分成正式版／試玩版）

```
深空當舖攻略/
├─ index.html          首頁：只有「正式版攻略」「試玩版攻略」兩個入口
├─ release.html        正式版攻略頁（<body data-ver="release">）
├─ demo.html           試玩版攻略頁（<body data-ver="demo">）
├─ assets/
│  ├─ app.js           兩頁共用的閱讀程式（版本名稱、徽章、首頁導讀文字在最上面的 PS_VERSIONS）
│  └─ style.css        共用樣式
├─ 記憶檔.md / CLAUDE.md
└─ strategies/
   ├─ _template.js     新流派範本
   ├─ release/         正式版：manifest.js + 15 個流派
   │    00-basics 01-trading 02-water 03-wine 04-rats 05-aquafarm 06-hydroponics
   │    07-smelting 08-chemistry 09-gunsmith 10-fence 11-appraisal 12-bounty 13-scavenge 14-vending

        00-overview 01-trading 02-water 03-wine 04-rats 07-machines
        10-fence 11-appraisal 12-bounty 13-hardmode
```

## 正式版／試玩版怎麼分

依「資料來源寫的是哪個版本」分：
- **試玩版**：來源標明 Demo / Playtest / Update 049，或 10/28 發售前寫的。目前是 probablystolen.top、18183、Stage1st 討論串、巴哈、知乎、probablystolenguides 的〈赚钱路线对比〉、Steam〈Winemaking and You〉〈Machinery and You〉、英文 Wiki 的老鼠頁。
- **正式版**：來源提到 1.0 / 發售後，或沒標版本的一般攻略站（bonus-action、showgamer、tposegaming、allthings.how、gameshorizon、outputlag、gamerblurb、游民星空、Steam 上 lpinch 化學指南、Owlie 賣水指南、From Nothing 困難開局指南）。
- 同一個流派兩邊都有時用同一個 `id`，正式版可以用 `<a href="demo.html#wine">` 連到試玩版那篇（釀酒、養鼠、鑑定、賞金已經這樣連）。
- 機器與模組資料表只放在試玩版（來源標明缺 1.0 資料）。

## 新增一個流派（3 步）

1. 複製 `strategies/_template.js` 到 `strategies/release/`（正式版）或 `strategies/demo/`（試玩版），改名 `NN-英文名.js`。
2. 改內容：`id` 在同一版本內不能重複、`order` 決定排序、`group` 用 `基礎 / 買賣 / 生產 / 灰色 / 黑色`。
3. 把檔名加進**同一個資料夾**的 `manifest.js`。

頁面不用改，首頁的流派數也會自動更新。網址 `release.html#英文id` / `demo.html#英文id` 可直接打開那篇。

## 資料格式

每個檔案做一件事：`window.PS_STRATEGIES.push({ ... })`。欄位：

| 欄位 | 說明 |
|---|---|
| `id` | 英文代號（網址用） |
| `order` | 數字，排序 |
| `icon` | 一個 emoji |
| `name` / `tagline` | 名稱 / 一句話介紹 |
| `group` | 分類（新分類要順便加到 index.html 的 `GROUPS` 和 CSS `--g-分類名` 顏色） |
| `stats` | `{capital, difficulty, risk, speed}` 各 1～5：起手資金、上手難度、風險、回本速度（越大越快） |
| `unlock` | 解鎖方式 |
| `tags` | 標籤陣列（點了會搜尋） |
| `sections` | 段落陣列，每段可有 `title`、`p`（字串或陣列）、`steps`（編號清單）、`list`、`table: {head, rows}`、`note`（黃框） |
| `tips` / `pitfalls` | 小技巧 / 地雷 |
| `sources` | `[{title, url}]` 資料來源 |
| `updated` | 最後更新日期 |

文字裡可用簡單 HTML（`<b>`、`<i>`、`<code>`）。字串裡有單引號要寫 `\'`。
改完可以用這行檢查語法：`for f in strategies/*/*.js; do node -e "global.window={};require('./$f')" || echo "壞掉: $f"; done`

## 更新既有流派

直接改對應的 js 檔，記得改 `updated` 日期，新來源加進 `sources`。
