網頁奇岩城（Lineage 3.5C）離線單機版
====================================

【這是什麼】
將「網頁奇岩城」（https://webl1.com/）完整中文化客戶端與資料表下載至本機，
並內建一套純本機運作的 L1J 3.5C 離線伺服器模擬器（js/offline-server.js）。
不需連線至官方伺服器、不受維修或斷線影響，在自己電腦即可 100% 離線單機遊玩！

【怎麼開始玩】
1. 確認電腦已安裝 Python 3（3.7 以上版本）。
2. 雙擊「開始遊戲.bat」（一般單機模式，網址 http://127.0.0.1:8391/）
   或雙擊「以GM模式開始遊戲.bat」（內建 GM 修改器模式，網址 http://127.0.0.1:8392/）。
3. 瀏覽器會自動打開遊戲畫面：
   - 在登入畫面輸入「任意帳號與密碼」即可直接登入。
   - 點擊「建立角色」選擇職業（王族、騎士、妖精、法師、黑暗妖精）與能力配點。
   - 新角色進世界即附贈豪華離線開局禮包（+6 祝福武器、全套安定防具、50 萬金幣、
     主城傳送石、傳送控制戒指、大量藥水、強化卷軸、魔法娃娃袋子與常用魔法）。
4. 遊玩時請保持黑色命令提示字元視窗開啟；結束遊玩時直接關掉黑色視窗即可。

【單機版特色與完整支援功能】
- 全地圖狩獵場傳送：新兵修練場、說話之島、銀騎士村莊、奇岩城鎮與各大野外／地監皆可傳送。
- AUTO 自動打怪練功：支援伺服器端自動尋怪、自動喝水、自動揀寶、掛機統計紀錄。
- 村莊與遠端 NPC 服務：隨時隨地可開啟 NPC 商店買賣、製作工匠（免材料不足煩惱，一鍵合成）、
  魔法商人（一鍵施加 30 分鐘全套神級增益）、精靈屬性選擇、倉庫等。
- 裝備強化與變身：支援武器／防具強化卷軸、祝福賦予卷軸、一起強化（單機版衝裝失敗不爆裝！），
  以及全等級變形卷軸、三段加速（巧克力蛋糕）。
- 魔法娃娃系統：支援開娃娃袋／盒子、娃娃合成、登入圖鑑與免費召喚跟隨。

【GM 模式專屬功能】（雙擊「以GM模式開始遊戲.bat」）
- 畫面右下角會出現紅金配色的「GM」懸浮按鈕，點擊即可打開 GM 修改器面板：
  1. 快速作弊：一鍵升 1 級 / 升 10 級 / 直升 Lv.99、滿血滿魔、全套神級狀態、金幣 +100萬 / +1,000萬、
     一鍵學會全部 145 種魔法、一鍵解鎖全部 50 種魔法娃娃。
  2. 戰鬥與衝裝特權：可隨時切換「無敵模式」（怪物打不痛＋卷軸強化 100% 必過）、
     「一擊必殺」（普攻／魔法秒殺怪物），以及調整經驗倍率（1x～100x）、掉寶倍率（1x～50x）、金幣倍率。
  3. 全身裝備一鍵強化：可將身上穿戴的武器、防具與飾品一鍵改為 +6 / +9 / +12 / +15 祝福神裝。
  4. 道具搜尋與創造：可從 2,650 種天堂 3.5C 道具中搜尋任何武器、防具、飾品、卷軸或寶箱，
     自訂強化值（+0～+15）、祝福狀態與數量後直接發送到背包。
  5. 等級與六圍修改：自由修改 Lv、HP/MP 上限、正義值，或一鍵將六圍（力/敏/體/智/精/魅）點滿 50。
  6. 聊天框指令：在遊戲聊天框輸入「.道具名稱」（例如「.克特之劍」或「.對武器施法的卷軸」）
     即可呼叫遊戲內建的 GM 建立物品視窗！
- GM 模式的存檔（埠號 8392）與一般模式（埠號 8391）完全獨立分開，並會自動備份至 saves\ 資料夾。

【自動更新】
- 每次雙擊「開始遊戲.bat」／「以GM模式開始遊戲.bat」，會先花幾秒檢查有沒有新的修補檔，有就自動下載套用再開遊戲；
  沒有網路、連不上就直接略過，照常開遊戲。
- 也可以雙擊「更新遊戲.bat」手動更新：
    1 ＝檢查並套用更新（修補檔）
    2 ＝同上，再把官網（webl1.com）的新版程式也同步下來（離線版改過的檔案會保留；對不上會自動還原）
    3 ＝還原上一次更新
- 被換掉的舊檔案備份在「更新備份」資料夾（留最近 5 次）。存檔（saves 資料夾）不會被更新動到。
- 不想自動更新：在 tools 資料夾建立 update_config.json，內容寫 {"auto_update": false}

【存檔】
- 角色存檔同時存在瀏覽器和 saves 資料夾；瀏覽器資料被清掉、換瀏覽器時，會自動從 saves 資料夾還原。
- saves\backup 每天自動留一份備份（最近 7 天）。
- 要全部重來：關掉遊戲，雙擊「重置所有角色與存檔.bat」。

【資料夾結構說明】
更新遊戲.bat           手動檢查更新／同步官網程式／還原上一次更新
tools\auto_updater.py  自動更新程式
開始遊戲.bat           一般離線單機模式啟動器（埠號 8391）
以GM模式開始遊戲.bat   GM 修改器模式啟動器（埠號 8392）
webl1_offline.py       本機伺服器主程式（零第三方套件依賴，僅用 Python 內建模組）
gm.js                  GM 模式懸浮修改器面板
js\offline-server.js   本機 L1J 3.5C 離線遊戲伺服器模擬器
data\、assets\、gfx\   已下載的遊戲地圖、資料表、職業動作、怪物與特效素材（共約 9,000 個檔案）
saves\                 自動備份的離線角色存檔
