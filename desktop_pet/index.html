放置希望桌寵

遊戲在背景照常掛機，桌面上留一隻桌寵陪你工作

下載安裝檔

版本 1.4.0・約 90 MB・Windows 10／11（64 位元）

已經裝過 1.3.0 以後版本的人不用重新下載，桌寵會自己更新。

安裝須知

  1. 按上面的「下載安裝檔」，檔案會直接從 GitHub 下載到電腦裡（約 90 MB）。
  2. 雙擊下載回來的 hope-desktop-pet-setup-x.x.x.exe。
  3. Windows 會跳出藍色的「Windows 已保護您的電腦」。這是因為安裝檔沒有購買數位簽章，不是中毒。
    按 其他資訊 → 仍要執行。
  4. 安裝完桌寵會自己啟動，桌面和開始功能表會多一個「放置希望桌寵」的捷徑。

裝之前先知道

  • 不要同時在瀏覽器開遊戲。桌寵裡的遊戲和瀏覽器裡的是兩份各自的存檔，兩邊一起玩進度會分岔，最後只能留一份。
  • 需要網路。桌寵裡跑的就是官方的遊戲網頁，遊戲改版會自動跟上。
  • 只支援 Windows 電腦，手機和 Mac 不能用。
  • 會多佔大約 300～500 MB 記憶體，跟多開一個瀏覽器分頁差不多。
  • 之後有新版，桌寵會自己下載（通常只有幾百 KB），下載好會開口問你要不要重新啟動。
  • 解除安裝從 Windows「設定 → 應用程式」移除即可，存檔會留在電腦裡。

第一次使用

  1. 第一次啟動會跳出操作說明，遊戲視窗也會自己出現。
  2. 新玩家：直接在遊戲視窗建角色開始玩。
  3. 已經有在玩：先在原本玩的地方（瀏覽器）用遊戲的「匯出存檔」存成檔案，再對桌寵按右鍵 → 存檔管理… → 從檔案匯入 選那個檔案。也可以用遊戲的轉移碼，在存檔管理裡輸入六碼。
  4. 匯入後角色如果站在村莊裡不會打怪，到遊戲視窗按一次 出發。
  5. 之後就只在桌寵裡玩，把遊戲視窗關掉（或按 Ctrl Alt H）它會藏起來繼續掛機。

換電腦時到「存檔管理…」匯出存檔或產生轉移碼，在另一台匯入。兩台電腦不要同時掛同一個角色。

常見問題

開了專注模式之後點不到桌寵

三種方法都可以解除：按 Ctrl Alt P、按住 Ctrl 再對桌寵按右鍵、或再點一次桌面上的捷徑。

找不到桌寵

再點一次桌面捷徑，桌寵和遊戲視窗都會被叫出來。也可以從畫面右下角系統匣的兔子圖示操作。

角色沒有在打怪

把遊戲視窗叫出來看一下。通常是角色人在村莊，按「出發」就好。

快捷鍵沒反應

可能被別的程式佔用了。改用對桌寵點兩下、右鍵選單，或系統匣的兔子圖示。

收益表的數字是怎麼算的

打怪收入是掉落物照商店賣價估的價值；淨收入是自動販售收入減掉三種支出，也就是金幣實際的增減。只記這次開啟桌寵以來的資料，重新啟動就會歸零。
