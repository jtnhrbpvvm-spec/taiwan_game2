放置希望桌寵

需要一個權限

桌寵要顯示在其他 App 上面，請開啟「顯示在其他應用程式上層」（有些手機叫「浮動視窗」「懸浮視窗」）。按下面的按鈕會帶你到設定頁，把開關打開後回到這裡。

出現「應用程式存取權已遭拒絕」的話

這是安卓對「不是從商店安裝的 App」多加的一道保護，要先手動解除一次：

  1. 先按「關閉」。
  2. 按下面的「打開應用程式資訊」。
  3. 按畫面右上角的「⋮」（三個點），選「允許受限制的設定」，照手機的指示驗證。
  4. 回到這裡，再按一次上面的「前往開啟權限」。

找不到「⋮」的話：到手機的「設定 → 應用程式 → 放置希望桌寵」，在那個畫面的右上角。要先看過一次「已遭拒絕」的訊息，那個選項才會出現。

有新版

按下面的按鈕下載，下載完會跳出系統的安裝畫面，再按一次「更新」就完成了。存檔和設定都會保留。

要先進遊戲選好角色，才讀得到外觀清單。

怎麼用

遊戲會在背景繼續掛機，畫面上留一隻桌寵。不要同時在瀏覽器開遊戲，兩邊的進度會互相蓋掉。

點桌寵打開遊戲。按上方的「收起」或返回鍵收回去
按住拖曳把桌寵移到別的位置
長按桌寵打開這個設定畫面
通知列顯示遊戲、設定、結束

第一次使用

遊戲畫面會自己打開。新玩家直接建角色；已經有在玩的話，在選角畫面用轉移碼取回，或按「匯入」選存檔檔案。

在選角畫面按「匯出」，存檔會放到手機的「下載」資料夾。

要注意的事

為了讓螢幕關掉後繼續掛機，手機不會進入深度待機，會比平常耗電。

有些品牌的手機（小米、OPPO、vivo、三星等）會自動關掉背景的 App。遇到掛機中斷的話，到手機設定把這個 App 的電池用量改成「不受限制」，並允許自動啟動。
